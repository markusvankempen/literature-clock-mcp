Hosted server

Save the file. Open Cursor Settings → MCP and turn literature-clock-mcp on. A green dot means the handshake worked. In Agent chat, ask: ask literature-clock-mcp for the current quote.

Streamable HTTP

{
  "mcpServers": {
    "literature-clock-mcp": {
      "url": "https://literature-clock-mcp.onrender.com/mcp"
    }
  }
}

Local npx

Cursor starts the process. stdio is the default. Node.js 20 or newer is required.

stdio

{
  "mcpServers": {
    "literature-clock-mcp": {
      "command": "npx",
      "args": ["-y", "literature-clock-mcp"]
    }
  }
}

When a key is required

Auth is off on a fresh server. When auth mode is write or all, add the header on the hosted entry.

{
  "mcpServers": {
    "literature-clock-mcp": {
      "url": "https://literature-clock-mcp.onrender.com/mcp",
      "headers": {
        "Authorization": "Bearer <key>"
      }
    }
  }
}

The clock on Render is UTC. “Now” on that host is the container’s minute, not the minute on your laptop. The first call after a free instance has been idle can take a moment.
