This is the custom-client stream. The first frame is event: ready. Later frames are event: quote. Push a quote now calls push_quote on the same server. That tool stays off until Settings turns on Allow this client to push a quote now, or the clock’s Settings → Push does. Subscribe, then press the button. The line arrives on this stream without waiting for the minute.

Serve this folder from localhost. A loopback page may open the stream. A page on another site is refused until CORS_ORIGINS includes that origin. The browser’s EventSource cannot set a bearer key, so this page uses fetch and reads the stream.

const stream = new EventSource("https://literature-clock-mcp.onrender.com/events");
stream.addEventListener("ready", (event) => {
  console.log("ready", JSON.parse(event.data));
});
stream.addEventListener("quote", (event) => {
  console.log("quote", JSON.parse(event.data));
});

curl keeps the stream open: curl -N https://literature-clock-mcp.onrender.com/events. Legacy MCP sessions use GET /sse and receive notifications/literature-clock/quote when that destination is on. An open Streamable HTTP session can receive the same notification.
