Literature Clock MCP · literature-clock-mcp

Clients Cursor VS Code Claude Browser

These pages are the copy you paste into an editor, and a browser that calls get_quote over Streamable HTTP.

The server is the npm package literature-clock-mcp. A hosted clock is at literature-clock-mcp.onrender.com. Its MCP URL is https://literature-clock-mcp.onrender.com/mcp.

Cursor ~/.cursor/mcp.json or .cursor/mcp.json. stdio through npx, or a hosted URL. VS Code User or workspace mcp.json, with type set to stdio or http. Claude Desktop A local npx process, or mcp-remote when the clock is hosted. Browser A page that posts tools/call for get_quote and shows the line.

Open these pages

Open index.html in a browser. The browser client calls another origin, so serve this folder on localhost. The server allows a loopback page. A page hosted elsewhere is refused until CORS_ORIGINS lists that origin.

cd clients
python3 -m http.server 8765

Then open http://127.0.0.1:8765/. Point the browser page at http://127.0.0.1:8080/mcp after MCP_MODE=http npx literature-clock-mcp, or at the Render URL above.

IBM Code Engine uses the same JSON as Cursor and VS Code. Replace the URL with https://<app>.<region>.codeengine.appdomain.cloud/mcp.
